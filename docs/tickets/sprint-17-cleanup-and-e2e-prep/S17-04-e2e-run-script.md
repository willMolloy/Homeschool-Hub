# S17-04 — The end-to-end run script
**Size:** S
## Goal
A written script for the end-to-end run (a person or an agent walks it), so the run after this sprint is quick and repeatable.
## Steps
1. `docs/e2e/cm-term-run-2.md`: a step-by-step walk through a term with the S17-03 family — first-run setup for a new family, adding the term's books (Add several and CSV), the Year and month views, a week adjustment, Update status, completion answers (finished early, stopped, not yet), logging a week (including a run of days), Records, export, printable sheets, term in review, a second parent, a viewer and the co-op switch, undo — each step with what to check.
2. A short "score" table to fill in (works / confusing / broken) like the Sprint 7 run (`docs/reviews/cm-term-run.md`).
## Done when
- The script covers every core feature in under about 90 minutes of walking.

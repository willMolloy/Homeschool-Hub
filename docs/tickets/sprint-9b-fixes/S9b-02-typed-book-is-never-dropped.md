# S9b-02 — A typed book is never dropped
**Finding:** N3 · **Size:** XS
## Goal
A book title typed in the log form but not added with "Add" is saved with the entry (or Save asks: "Add 'Charlotte's Web'?"). Choose the first: add it on Save.
## Done when
- Typing a title and pressing Save keeps the book.
## Tests
- Web: pending title is included in the saved body.

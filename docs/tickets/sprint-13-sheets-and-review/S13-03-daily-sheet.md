# S13-03 — The daily sheet
**Size:** S
## Steps
1. Same look as the weekly sheet, for one day: the child's name and the date ("Tuesday, Nov 3"); only the assignments scheduled on that weekday, each with that day's range and a checkbox; a notes area.
2. A day with nothing scheduled (a day off or a weekend) prints "Nothing planned for Tuesday" for that child.
## Done when
- The demo family's Tuesday shows only Tuesday's work per child.
## Tests
- Web: weekday filter, day off, ranges.

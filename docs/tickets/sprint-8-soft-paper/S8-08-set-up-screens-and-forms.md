# S8-08 — Set up screens and forms in Soft Paper

**Source:** `design/ux-research.md` §5 "One Setup list: Subjects"  
**Depends on:** S8-04  
**Size:** M

## Goal
Children, Subjects, Assignments, Days off and breaks, Events and Family settings use the Soft Paper list and form patterns.

## Steps
1. Lists: List rows with a colour dot (subjects), a one-line summary, and a chevron; "Add" as a primary pill; panels (Add several, Import CSV, templates, copy) as sheets.
2. Forms: grouped fields on cards, the date popover, steppers for totals, chips for days; essentials first, the rest under "More".
3. Keep every behaviour and validation as is.

## Done when
- Every setup screen uses the shared components and patterns; nothing behaves differently; 360 px with 44 px targets.

## Tests
- Existing screen tests pass; before/after screenshots.

## Out of scope
- New setup features.
